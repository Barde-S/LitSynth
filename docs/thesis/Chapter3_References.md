## In-Text Citation Examples

Use the following formats when citing in the thesis text:

### Single Author:
- Narrative: Sommerville (2015) describes requirements engineering as...
- Parenthetical: The iterative model supports continuous refinement (Pressman, 2014).

### Multiple Authors (3+):
- First citation: Lewis et al. (2020) introduced Retrieval-Augmented Generation...
- Subsequent: Lewis et al. (2020) demonstrated that...

### Multiple Works in Same Citation:
- Several software engineering methodologies have been proposed (Pressman, 2014; Sommerville, 2015).

### Direct Quote:
- Pressman (2014, p. 42) states that "the Iterative Incremental model is a software development approach where the system is developed through repeated cycles."

## Creating the Reference List in Your Thesis

In your final thesis document (Word or LaTeX), create a **References** or **Bibliography** section at the end with these entries in alphabetical order by first author's last name.

### APA Format Requirements:

1. **Hanging indent**: Second and subsequent lines indented 0.5 inches
2. **Alphabetical order**: By first author's surname
3. **Double spacing**: Between all entries
4. **Italics**: For book titles and journal names
5. **DOI or URL**: Include when available

### Example Reference Page Layout:

```
REFERENCES

Booch, G., Rumbaugh, J., & Jacobson, I. (2005). The Unified Modeling Language user
```

   - Generates bibliographies automatically
   - https://www.zotero.org

2. **Mendeley** (Free)
   - PDF management with annotations
   - Desktop and web versions
   - Citation plugin for Word
   - https://www.mendeley.com

3. **EndNote** (Paid, often available through universities)
   - Professional features
   - Strong academic support
   - https://endnote.com
