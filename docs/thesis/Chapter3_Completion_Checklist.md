## Common Issues and Solutions

### Issue 1: Diagrams too large for page
**Solution**:
- Reduce diagram complexity or split into multiple diagrams
- Use landscape orientation for that specific page
- Reduce font size slightly (minimum 9pt)

### Issue 2: Use case tables break across pages
**Solution**:
- Use "Keep with next" paragraph setting
- Or use "Keep lines together" table property
- Manually adjust page breaks

### Issue 3: Figure numbers out of sequence
**Solution**:
- Use Word's automatic figure numbering feature
- Or manually verify all figure numbers before submission

### Issue 4: References not formatting correctly
**Solution**:
- Use Zotero or Mendeley plugin for automatic formatting
- Or manually verify against APA 7th edition guide

### Issue 5: Inconsistent terminology
**Solution**:
- Use Find & Replace to standardize terms
- Create terminology glossary for reference
